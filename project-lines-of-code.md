## How the lines were counted

Each repo was shallow-cloned from GitHub and the non-blank lines in its source files were counted: JavaScript, TypeScript, C#, Python, HTML, CSS, PowerShell and batch files. Not counted: `node_modules`, `dist`, `build`, `bin` and `obj` folders, hidden folders, minified files, `.d.ts` files, and Markdown, JSON and other config or data files. SVG only counts where it holds code (the Color Picker).

1. The repo only holds a README.
2. The repo only holds David Bellot's SVG artwork, not code.
3. Leaves out `data/subscriptions.js` (2,042 lines), which is a generated data file of channels.
4. Not linked on the site; it matches the project's description ("Free Aurora Forecast Data App"). The repo only holds a README, a licence and a `.gitignore`.
5. Not linked as source on the site; found through the card's live demo link, `jjkramhoeft.github.io/color-picker`.
